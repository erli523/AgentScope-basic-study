# 04 Context

## 学习内容

- 多轮消息如何进入模型上下文；
- 上下文窗口和 token 成本；
- 历史裁剪、摘要和关键信息保留；
- Context 与 Session、RAG、长期记忆的区别。

## 学习重点

上下文不是越长越好。无关历史会增加成本、降低回答质量，并可能把旧错误带入后续轮次。

## 实践任务

实现一个多轮对话，达到阈值后压缩旧消息。测试压缩后 Agent 是否仍保留任务目标和关键约束。

## 验收标准

- 能说明哪些消息应进入下一次模型调用；
- 能限制上下文增长；
- 能在摘要后保留关键事实；
- 能区分短期上下文、外部知识和跨会话记忆。
