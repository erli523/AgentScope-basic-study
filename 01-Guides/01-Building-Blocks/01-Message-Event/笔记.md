# 01 Message 与 Event — 学习笔记

> 笔记内容主要针对官网文档整理。

## 1. 一句话区分

| 概念 | 是什么 | 负责什么 |
|------|--------|----------|
| **消息（Message / Msg）** | 智能体间通信与上下文持久化的基本单元 | 传递「内容」 |
| **事件（Event）** | 前后端交互与流式传输的基本单元，也支持 Human-in-the-loop | 告诉「发生了什么」 |

可以记成：

- 消息只负责传递内容；
- 事件来负责告诉过程中发生了什么。

## 2. 创建消息

最简单的用法：字符串会自动包成 `TextBlock`。

```python
user_msg = UserMsg(
    name="user",
    content="帮我分析一下当前目录中的代码。",
)
```

官方提供的 `UserMsg`、`AssistantMsg`、`SystemMsg` 都支持这种自动转换，等价于：

```python
user_msg = UserMsg(
    name="user",
    content=[
        TextBlock(text="帮我分析一下当前目录中的代码。"),
    ],
)
```

如果还要图片等其他内容，就需要自己在 `content` 里写多个块：

```python
user_msg = UserMsg(
    name="user",
    content=[
        TextBlock(text="请分析这张系统架构图。"),
        DataBlock(
            name="architecture.png",
            source=URLSource(
                url="https://example.com/architecture.png",
                media_type="image/png",
            ),
        ),
    ],
)
```

也就是说：**纯文本可以偷懒用字符串；其他内容块需要显式写在 `content` 里。**

## 3. 如何查看消息内容

```python
result = await agent.reply(msg)
for block in result.content:
    print(block.type)
    print(block)  # 块的内容
```

获取工具调用：

```python
tool_calls = result.get_content_blocks("tool_call")
for call in tool_calls:
    print("工具名称：", call.name)
    print("工具参数：", call.input)
    print("工具状态：", call.state)
```

体会：消息相关的封装比较方便，至少在获取信息上比较顺手。

## 4. 事件与从事件还原消息

AgentScope **没有**名为 `event_id` 的字段，但每个事件都有自己的 `id`。

从流式事件重建一条助手消息：

```python
async for event in agent.reply_stream(msg):
    if isinstance(event, ReplyStartEvent):
        msg = AssistantMsg(name=event.name, content=[], id=event.reply_id)
    else:
        # 其他事件追加到消息，逐步还原状态
        msg.append_event(event)
```

要点：

- `ReplyStart` 时先建空壳 `AssistantMsg`，`id` 要对齐 `reply_id`；
- 后续事件用 `append_event` 往里填。

## 5. 前端如何接收事件并实时渲染

```python
msg = None
async for event in agent.reply_stream(UserMsg("user", "帮我修复这个 bug")):
    if isinstance(event, ReplyStartEvent):
        msg = AssistantMsg(name=event.name, content=[], id=event.reply_id)

    elif isinstance(event, TextBlockDeltaEvent):
        print(event.delta, end="", flush=True)

    elif isinstance(event, ToolCallStartEvent):
        print(f"\n[正在调用 {event.tool_call_name}...]")

    elif isinstance(event, ToolResultEndEvent):
        print(f"[工具执行完成：{event.state}]")

    elif isinstance(event, ReplyEndEvent):
        print("\n[完成]")

    # 始终将事件追加到消息中
    if msg is not None:
        msg.append_event(event)
```

一边按事件类型做 UI/日志展示，一边用同一条 `msg` 做完整还原。
