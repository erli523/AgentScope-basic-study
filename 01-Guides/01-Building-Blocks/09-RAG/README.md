# 09 RAG

## 学习内容

- 文档导入、清洗、切块和元数据；
- Embedding、向量索引和检索；
- 查询改写、召回、重排和引用；
- RAG 工具如何接入 Agent。

## 学习重点

RAG 的核心是检索质量和来源可信度。必须评估是否召回正确内容，并防止文档中的提示注入影响 Agent 权限。

## 实践任务

把本学习手册作为知识库，实现“询问某章节学习目标”的 Agent，并返回文件名或链接作为来源。

## 验收标准

- 回答能够追溯到具体文档；
- 无答案时不会编造；
- 能用一组固定问题评估召回率和答案质量；
- 文档内容不能获得额外工具权限。
