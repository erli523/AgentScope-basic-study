# 03 Model

## 学习内容

- 模型客户端和 Credential；
- 模型名称、温度、最大输出等参数；
- 流式响应、工具调用、结构化输出和多模态能力；
- 不同模型供应商之间的能力差异。

## 学习重点

模型配置应与 Agent 业务逻辑解耦。API Key 不得硬编码；切换模型时还要检查工具调用、上下文窗口和结构化输出是否兼容。

## 实践任务

用同一个 Agent 配置两种模型，通过环境变量选择模型，并记录它们在工具调用和流式事件上的差异。

## 验收标准

- 能安全加载模型凭证；
- 能更换模型而不重写 Agent；
- 能识别模型不支持某种能力时的失败；
- 能为开发、测试和生产使用不同配置。
