# 07 Permission System

## 学习内容

- 工具和资源的权限判断；
- allow、deny、人工确认等决策；
- 权限规则与用户、会话、资源路径和动作的关系；
- 权限事件和审计记录。

## 学习重点

权限必须由代码强制执行，不能只依赖系统提示词。采用最小权限原则，默认拒绝未明确授权的高风险能力。

## 实践任务

配置读取笔记自动允许、修改笔记需要确认、删除目录始终拒绝，并测试路径穿越和伪造参数。

## 验收标准

- 未授权操作无法通过换一种提示词绕过；
- 审批界面能展示准确的动作和目标；
- 权限拒绝后 Agent 能合理结束或选择替代方案；
- 审计日志可以说明谁在何时批准了什么操作。
