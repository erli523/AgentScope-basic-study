# 08 Middleware

## 学习内容

- Agent 执行环节中的中间件和钩子；
- 日志、指标、重试、内容检查和上下文加工；
- 中间件组合顺序；
- 异常传播与资源清理。

## 学习重点

中间件适合横切能力，不应承载主要业务流程。需要明确中间件是否修改输入、输出或状态，以及多个中间件的先后依赖。

## 实践任务

实现一个耗时统计中间件和一个敏感信息脱敏中间件，验证模型异常和工具异常时仍能记录结束状态。

## 验收标准

- 不修改 Agent 代码即可启用或关闭中间件；
- 中间件顺序可预测；
- 异常时仍能正确清理和记录；
- 不会重复执行有副作用的工具。
