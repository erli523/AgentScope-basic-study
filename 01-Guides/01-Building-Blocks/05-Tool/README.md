# 05 Tool

## 学习内容

- Toolkit 与工具注册；
- 工具名称、描述、参数 Schema 和返回值；
- 同步/异步工具、超时和异常；
- 文件、HTTP、数据库和 MCP 类型工具。

## 学习重点

工具描述决定模型是否会正确选择工具；工具实现则必须校验输入、限制副作用、处理超时并返回结构化错误。

## 实践任务

编写“读取学习笔记”和“搜索章节名称”两个只读工具，再设计一个需要权限确认的写入工具。

## 验收标准

- 模型能稳定选择正确工具；
- 参数错误和业务错误不会导致进程崩溃；
- 写操作具有幂等或重复调用保护；
- 工具拥有独立单元测试，不依赖 Agent 才能测试。
