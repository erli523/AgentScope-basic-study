# 04 RAG Service

## 学习内容

- 知识库创建、文档导入、索引构建和查询 API；
- 导入链路与在线查询链路分离；
- 多租户、多会话和权限过滤；
- 索引版本、更新、删除和监控。

## 学习重点

服务化 RAG 不只是把本地检索包一层 HTTP。必须处理知识库归属、文档可见性、异步导入状态和索引版本。

## 实践任务

建立一个共享的 AgentScope 文档知识库，允许两个 Agent 查询，但限制它们只能访问授权文档集合。

## 验收标准

- 文档导入和查询可以独立扩缩容；
- 查询结果带知识库、文档和片段标识；
- 删除文档后不会继续被召回；
- 不同租户的文档严格隔离。
