# 03 Resource Sharing

## 学习内容

- 模型客户端、工具、存储、RAG 和 Workspace 等资源的共享方式；
- 资源所有权、引用和生命周期；
- 并发访问与连接池；
- 多租户和多会话隔离。

## 学习重点

共享资源可以降低成本，但不能破坏状态隔离。无状态客户端通常更容易共享；会话上下文、用户记忆和工作目录通常必须隔离。

## 实践任务

为模型客户端、向量索引、会话 Context 和 Workspace 分别设计共享策略，并解释原因。

## 验收标准

- 能区分全局、租户、会话和单次运行级资源；
- 不同用户不会读到彼此状态；
- 并发访问不会破坏共享资源；
- 服务关闭时资源能够有序释放。
